# 🛍️ MOODk — Modern Fashion E-Commerce Store

**MOODk** is a modern and responsive fashion e-commerce website designed to provide a smooth and engaging online shopping experience for **Men, Women, and Kids**.

The project focuses on building a complete front-end shopping experience with modern UI, interactive components, product browsing, cart management, wishlist functionality, authentication pages, checkout flow, order management, and responsive design.

---

### 🎨 Responsive Design

MOODk is designed to work across different screen sizes:

*  Desktop
*  Laptop
*  Mobile
*  Tablet

---

## 🛠️ Technologies Used

### Front-End

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**

### UI & Animation

* CSS Animations & Transitions
* Responsive Design
* DOM Manipulation
* Interactive UI Components
* GSAP / ScrollTrigger where applicable

### Browser Storage

* `localStorage`
* `sessionStorage`

Used for maintaining client-side data such as:

* Cart
* Wishlist
* User session
* Orders
* Product information
* Order timing
